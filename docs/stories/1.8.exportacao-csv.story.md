# Story 1.8: Exportação CSV de Relatórios

## Status
Done

## Complexidade
**S** (Small) — Export client-side puro, sem novas dependências, dados já disponíveis no estado da página.

## Dependências
**Requer:** Story 1.7 (lista de produtos com métricas). Story 1.4 (custos lançados por etapa).

## Escopo
**IN:** Botão "Exportar CSV" na página `/produtos` (exporta lista filtrada). Botão "Exportar CSV" na página `/produtos/[id]/custos` (exporta breakdown de custos). Utilitário `lib/export-csv.ts` reutilizável. Nome do arquivo com data atual. UTF-8 BOM para compatibilidade com Excel.
**OUT:** Export PDF. Export de gráficos como imagem. Seleção de colunas. Agendamento de relatórios. Import CSV. Envio por e-mail.

## Riscos
- **Caracteres especiais:** Acentos e vírgulas em nomes podem corromper CSV. Mitigação: UTF-8 BOM + escape de campos com aspas duplas.
- **Volume:** MVP limita a 100 produtos — sem risco de memória.

## Story
**As a** gestor,
**I want** exportar os dados de produtos e custos em CSV,

## Acceptance Criteria
1. Botão "Exportar CSV" visível em `/produtos` quando há pelo menos 1 produto listado
2. CSV de produtos inclui: Nome, Categoria, Canal de Venda, Status, Progresso (%), Etapas Concluídas, Total Etapas, Custo Real (R$), Desvio Custo, Data de Início, Recebimento Estimado
3. CSV exportado reflete a lista **filtrada** (não todos os produtos se filtros estiverem ativos)
4. Botão "Exportar CSV" visível em `/produtos/[id]/custos` quando há ao menos 1 custo lançado
5. CSV de custos inclui: Etapa, Tipo, Descrição, Valor Planejado (R$), Valor Real (R$), Data Lançamento
6. Nome do arquivo inclui data atual: `produtos-YYYY-MM-DD.csv` e `custos-YYYY-MM-DD.csv`
7. Arquivo abre corretamente no Excel/Sheets com acentos (UTF-8 BOM)
8. Zero novas dependências npm adicionadas

## Dev Notes

**Utilitário CSV:** Criar em `lib/export-csv.ts`. Função pura, reutilizável, zero deps.

**BOM:** `'﻿'` prefixado no CSV para Excel reconhecer UTF-8 automaticamente.

**Escape rule:** Se o valor contém `,`, `"` ou `\n`, envolver em aspas duplas e duplicar aspas internas.

**Formatação numérica no CSV:** Usar valores numéricos brutos (não `Intl.NumberFormat`) para que Excel processe como número. Ex: `150.00` não `R$ 150,00`.

**Download pattern:**
```ts
const blob = new Blob(['﻿' + csv], { type: 'text/csv;charset=utf-8;' });
const url = URL.createObjectURL(blob);
const a = document.createElement('a');
a.href = url; a.download = filename; a.click();
URL.revokeObjectURL(url);
```
